Como ativar o aviso automático

O número identifica quem recebe. Para enviar sem o cliente apertar “Enviar”, conecte o sistema a uma API ou automação.

  1. Confirme o número do barbeiro.
  2. Configure a API oficial do WhatsApp ou o webhook do seu provedor no servidor, seguindo o arquivo LEIA-PRIMEIRO.md.
  3. Faça uma reserva de teste e confira o aviso recebido no celular.
Ver configuração técnica

API oficial: WA_TOKEN, WA_PHONE_NUMBER_ID e modelo aprovado WA_TEMPLATE_NAME.

Automação: WHATSAPP_WEBHOOK_URL e, se usado, WHATSAPP_WEBHOOK_SECRET.
